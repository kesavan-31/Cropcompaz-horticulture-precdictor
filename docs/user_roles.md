# CropCompass User Roles & Access Matrix

## Stakeholder Roles

1. **Farmer**:
   - Provides farm acreage, budget constraints, equipment inventory, input quantities, labor availability, and water sources.
   - Receives resource-aware advisory recommendations and explainability breakdowns.

2. **Cooperative Staff / Extension Worker**:
   - Registers farmer profiles and updates resource inventories.
   - Triggers scenario evaluations and reviews historical recommendations.

3. **Agronomy Reviewer**:
   - Maintains and audits the agronomy rule database.
   - Assigns rule statuses (`APPROVED`, `DEMO`, `NEEDS_APPROVAL`, `INACTIVE`) and verifies evidence citations.

4. **Admin**:
   - Manages system configuration and monitors baseline vs. CropCompass accuracy metrics.

> [!NOTE]
> Authentication and role-based access control (RBAC) are scheduled for Phase 3 expansion.

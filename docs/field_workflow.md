# CropCompass Field Workflow

## Step-by-Step Field Process

```text
Farmer Profile Registration
       ↓
Resource Inventory (Equipment, Input Quantities, Water Source)
       ↓
Local Micro-Climate & Soil Conditions
       ↓
Advisory Request
       ↓
Approved Agronomy Rule Matching
       ↓
Resource Constraint Evaluation (Pass / Fail / Partial)
       ↓
Feasibility Score Computation
       ↓
Primary Recommendation & High Impact Detection
       ↓
Alternative Recommendation Selection (if primary fails)
       ↓
"Why?" Evidence & Source Citation Breakdown
       ↓
Historical Record Persistence
```
